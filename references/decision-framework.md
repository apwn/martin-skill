# Decision framework
KEEP: unique, necessary content. COMPRESS: useful but bloated. MERGE: overlapping visitor questions. MOVE: important but poorly ordered. DELETE: duplicate, irrelevant, unsupported or empty decoration.

For each section ask: What question does it answer? Is it answered elsewhere? Is it specific and true? Does it help understanding, trust or action? Is it in the right place? What would be lost?

High-risk: pricing, eligibility, legal, security, compatibility, navigation, forms. Preserve unless approved. Medium-risk: moving proof, merging important information. Low-risk: repeated vague marketing claims and filler.

Prefer concrete claims, real product demonstrations, descriptive headings, concise paragraphs, consistent CTA labels, purposeful whitespace. Never enforce a universal word, section or CTA count. Brutal mode means tougher on redundancy, not weaker safeguards.

## Value-first priority
Map each section to the customer outcome it communicates before deciding whether to keep, compress, merge, move or delete. If multiple sections enumerate features but none explains the outcome, rewrite the narrative around defensible value. Keep detailed specifications accessible when they matter.
