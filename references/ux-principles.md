# UX principles
NN/g supports concise, scannable, objective web writing in studied contexts, not a universal 50% conversion rule. Front-load information, use specific headings, clear verbs, short paragraphs and meaningful lists.

Hierarchy: visitors should quickly grasp product, audience and next action. Use product visuals where helpful. Keep purposeful whitespace and identity.

CTAs: clear primary action, legitimate secondary paths, consistent labels. Repetition after meaningful content may help. Preserve tracking and destinations.

Mobile: inspect narrow and wide layouts if browser tools exist; check overflow, text wrapping, hero height, sticky overlays, tap targets and focus. Disclose when visual QA is unavailable.

Accessibility: preserve semantic headings, labels, contrast, keyboard support, focus and alt text. WCAG 2.2 is a standard, not an automated certification.

SEO: preserve search intent, useful information, metadata, canonicals and structured data. Don't claim speed gains without measurement.
