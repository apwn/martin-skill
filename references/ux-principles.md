# UX principles
NN/g supports concise, scannable, objective web writing in studied contexts, not a universal 50% conversion rule. Front-load information, use specific headings, clear verbs, short paragraphs and meaningful lists.

Hierarchy: visitors should quickly grasp product, audience and next action (5-second test). One display headline, a smaller subhead, body, quiet captions. Scannable chunks. No walls of text. Use product visuals where they fit the hero budget. Keep purposeful whitespace and identity.

CTAs: one primary style. The label is the next step of the headline claim, not "Learn more". Repeat that same action later if needed. Preserve tracking and destinations.

Mobile: inspect 390x844 and 1440x900 if a browser exists. Check overflow, text wrapping, hero height, sticky overlays, focus, and tap targets (24x24 CSS px minimum, 44x44 for the primary CTA). Disclose when visual QA is unavailable.

Accessibility: preserve semantic headings, labels, contrast, keyboard support, focus and alt text. WCAG 2.2 is a standard, not an automated certification.

SEO: preserve search intent, useful information, metadata, canonicals and structured data. Don't claim speed gains without measurement.
