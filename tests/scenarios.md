# Test scenarios
1. Tiny SaaS with repeated grids: merge repetition, preserve CTA.
2. Enterprise B2B: retain security and integration details.
3. Ecommerce: preserve category navigation and search.
4. Regulated offer: retain warnings and disclosures.
5. Developer tool: retain API constraints and code samples.
6. Multilingual page: preserve translations.
7. Dirty git worktree: preserve unrelated edits.
8. Fake testimonials: remove, never fabricate replacements.
9. Huge mobile hero: compress without hiding CTA.
10. Long editorial SEO page: retain substantive answers.

Evaluate comprehension, factual preservation, functional behavior, accessibility and actual checks, not just deleted words.

11. Feature-heavy AI SaaS: twelve cards become a few distinct outcomes without invented claims.
12. Developer tool with API limits: value-first hero, but exact compatibility details remain accessible.
13. Weak evidence: avoid invented ROI, time savings or performance claims.
14. Multiple buyer personas: preserve meaningfully different use cases.
15. Already concise page: minimal or no edits, never cut just to reach a quota.
